## About the Website

This is my personal portfolio website created for my IWaMAD course.

The website introduces me and showcases three projects I completed during the course.

It also includes a dark/light mode switch and a contact form with JavaScript validation.

## Design Decisions

1. **Layout:** I chose a three-column project layout for desktop screens and a single-column layout for mobile phones so visitors can browse my projects easily.

2. **Colors:** I used a light neutral background with purple accents to create a clean design and make important buttons stand out.

3. **Responsive Design:** After testing the website at 375px, I adjusted the mobile spacing and navigation to make the content easier to read on smaller screens.
